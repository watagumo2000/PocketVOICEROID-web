# Logo

アプリのタイトルロゴ。大きく見せる場所（スプラッシュ、メインビジュアル、タイトル画面）は左の組みロゴ、ヘッダーやフッターなど小さい場所は右の文字ロゴ（`vp-wordmark`）を使います。

- 組みロゴは inline SVG で置く（文字に Fredoka を使うため、画像ファイルにすると書体が変わる）。幅は 280〜440px。
- 構成は固定：ピンクのピルに「VOICEROID」、その下に `pink`・`blue` を交互にした「POCKET」。「O」は `blue` の丸に `ink` の波形バー5本。フチと右下のずらし影は `ink`。
- 波形バーは 0.8 秒で伸び縮み、キラキラは点滅させる。視差効果を減らす設定では止まる。
- 文字ロゴは Fredoka 700。白地なら `ink`、`ink` の地なら `pink` で書く。
- 色を入れ替えたり、斜め2色の板を背景に敷いたりしない（検討して外した案）。
- 「VOICEROID」は株式会社AHSの商標です。表記は公式のガイドラインに従う。
