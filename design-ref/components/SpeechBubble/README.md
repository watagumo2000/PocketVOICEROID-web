# SpeechBubble

アプリの会話画面とウィジェットで、キャラのセリフを出す吹き出し。左上に名前の札、右下にキャラ色のずらし影。

- 茜は `vp-bubble`（`pink`）、葵は `vp-bubble vp-bubble--aoi`（`blue`）。名前の札（`vp-bubble__name`）にはキャラ名だけを入れる。
- 本文は 16px、太さ 700、行間 1.7。最大幅は 320px で、長いセリフは改行して2〜3行に収める。
- 続きがあるときは右下に「▼」（`vp-bubble__next`）。
- 2人が同時に話す画面では、茜を左、葵を右に寄せる。
- 紹介ページにはない、アプリのために追加した部品。形は QuoteBox と NamePlate から作っている。
