# DiagonalBands

太い平行四辺形と細い帯を並べた、このアプリの基本モチーフ。キャラやスマホ画面の後ろに敷きます。

- 親に `vp-bands` と高さを指定し、中に `vp-bands__main`（太い帯）と `vp-bands__sub`（細い帯）を置く。その上にキャラや画面を重ねる。
- 茜の画面は `vp-bands`（太い帯が `pink`）、葵の画面は `vp-bands vp-bands--aoi`（太い帯が `blue`）。
- 傾きは上辺が右にずれる向きで固定。左右反転しない。
- キラキラ（`vp-sparkle`）を2〜4個まわりに置いてよい。水玉（`vp-dots`）は画面の隅に1か所だけ。
- アプリでは、ホーム画面のキャラの背景や、キャラ切り替え画面の背景に使う。
