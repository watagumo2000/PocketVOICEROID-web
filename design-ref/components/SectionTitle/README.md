# SectionTitle

大きな白抜きの英字と、白座布団の日本語ラベルを重ねたセクション見出し。

- 英字（`vp-sec__en`）は大文字1語。塗りは `surface`、3px の `ink` フチ、6px のずらし影。
- 日本語（`vp-sec__ja`）は `heading-m`。フチの代わりに `shadow-label-*` で輪郭を出す。
- 影の色は英字と日本語で入れ替える。標準は英字が `pink`、ラベルが `blue`。`vp-sec--alt` で逆になる。セクションごとに交互に使う。
- 左寄せが基本。交互に右寄せ（`vp-sec--end`）にするとリズムが出る。
- PC幅は 104px、スマホ幅とアプリ画面は `vp-sec--sm`（56px）。
- 英字のほうは飾りなので、見出しの意味は日本語の `<h2>` に持たせる。
