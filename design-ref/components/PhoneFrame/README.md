# PhoneFrame

実際のアプリ画面を入れる、線画風のスマホ枠。白いベゼル、4px の `ink` フチ、8px のずらし影。

- 中身は `vp-phone__screen` の中に `<img>` で入れる（縦長のスクリーンショット、`object-fit: cover`）。用意できるまでは `vp-phone__empty` の点線で場所を示す。
- 幅は 260px が基準。比率は 260:563 で固定。
- 実機そっくりの枠（ノッチ、ボタン、反射）は描かない。ページの線画に合わせる。
- DiagonalBands の上に置くと、紹介ページの FEATURE と同じ見え方になる。
